# 🧪 Web Application QA Testing Project

A complete Manual and Automation Testing project covering functional, regression, smoke, and sanity testing for a web application.

---

## 📌 Project Overview

End-to-end quality assurance project demonstrating professional testing skills including test planning, test case design, test execution, defect reporting, and automation framework development.

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| Java | Programming Language |
| Selenium WebDriver | UI Automation |
| TestNG | Test Framework |
| Maven | Build Tool |
| Apache POI | Data-Driven Testing |
| Extent Reports | Reporting |
| Git & GitHub | Version Control |

---

## ✅ Modules Tested

- 🔐 User Login & Registration
- 🏠 Dashboard & Navigation
- 📝 Form Validations
- 🔍 Search Functionality
- ⚙️ Settings & Profile Management

- ✅ Regression Suite Automation
